# NullForge
This is a project designed to make the RX7600 work on a Hackintosh.

⚠️I want to make it clear right away that I'm not sure this project will actually work—even though I've seen projects like nullmoth, nullarc, and Cobalt64.

This project is only possible thanks to REA(Reverse Engineer Anything), Cobalt64 and NullArc

REA:https://github.com/morluto/rea
